Gallery 004D · Hands-on laboratory

Square.
Quarter. Project.

Six computational exhibits—and one coloring wall—turn the structures of four into things you can manipulate.

Experiment 01

The divisibility gate

For decimal integers, only the final two digits matter when testing divisibility by 4.

Experiment 02

The quaternary translator

Translate an integer into base 4. Each quaternary digit corresponds exactly to two binary bits.

Experiment 03

The quarter-turn wheel

Choose one of the four solutions of z⁴=1. The roots sit 90 degrees apart on the unit circle.

1i−1−i
Experiment 04

The four-square finder

Give the machine a nonnegative integer. It searches for a²+b²+c²+d²=n, illustrating Lagrange's theorem.

Experiment 05

The hypercube ladder

Move from a point through line, square, cube, and tesseract. An n-dimensional hypercube has 2ⁿ vertices.

Experiment 06

The square-power engine

Watch powers of four grow. Because 4ⁿ=2²ⁿ, every step multiplies the previous value by four and doubles the binary exponent.

Bonus wall

Color a map with four paints.

Click a region to cycle through four colors. The wall checks orthogonally adjacent cells; equal colors on a shared edge create a conflict. This grid is only a playful finite example—the Four Color Theorem concerns every planar map.
